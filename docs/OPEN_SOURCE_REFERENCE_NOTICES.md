# Open-source reference acknowledgements

This project studies public repositories for architectural and algorithmic ideas. The target implementation is Python-native. No complete third-party application is embedded, and no third-party source file is copied verbatim unless its license permits the specific reuse and the required notices are retained.

- **HyperData Terminal** — Apache License 2.0, Copyright (c) 2026 Co-Messi. Reference: https://github.com/Co-Messi/HyperData-Terminal. Reviewed patterns: per-venue freshness/coverage, event-ID deduplication, CVD warm-up, liquidation evidence classes and data-health reporting. Any future source-code reuse must retain Apache-2.0 notices and comply with its conditions.
- **million** — MIT, Copyright (c) 2026 Kelows. Reference: https://github.com/Kelows/million. Reviewed patterns: wallet/token discovery, wallet-quality filtering, event-driven ingestion and decision logs. The Node/NestJS application, Prisma schema and Helius runtime are not embedded. Source audit also documented event-attribution, durability and ledger limitations; see docs/REFERENCE_REPOSITORY_ADAPTATION.md.
- **TradeClaw** — MIT License, Copyright (c) 2026 TradeClaw Contributors. Correct reference: https://github.com/tradeclaw-labs/tradeclaw. Reviewed patterns: simulation-first workflow, explicit trade records and safety limits. Its inspected backtest engine does not deduct fees or slippage, so its headline backtest returns are not adopted as performance evidence. Existing Crypto Super Radar cost-aware analytics and walk-forward validation are implemented independently in the Python codebase.
- **Solbeam** — Reference reviewed: https://github.com/CodeMuscle/solbeam. GitHub repository metadata did not declare a license at review time. No source code is copied. Publicly described concepts (explainable risk components, hard disqualifiers, holder/deployer risk) may be independently reimplemented, with missing evidence kept UNKNOWN; the reviewed source contains placeholder inputs that must not be treated as verified observations.

The reference audit and the distinction between existing target functionality and remaining work are recorded in docs/REFERENCE_REPOSITORY_ADAPTATION.md. These acknowledgements do not imply that every feature of the referenced repositories is implemented in Crypto Super Radar.
